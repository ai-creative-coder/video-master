# 模式选择提示

每次调用本 Skill 都读取本文件，并在普通对话中询问一次。用户确认后不要再次询问。

## 必须展示的选择

直接向用户显示以下两项并等待其回复。不要调用弹窗、表单或结构化选择工具。

### 标准模式

- 适合：大多数短视频、单一或少量场景、人物关系简单、VFX 复杂度一般。
- 编排：主 Agent + 1 个视觉综合 Agent；叙事与声音综合 Agent 仅在存在对白、人物关系、叙事因果、声音节拍或相关未知项时启动，因此通常为 1–2 个子 Agent。
- 交付：完整故事剧本与图文分镜故事板。故事板内部整合人物/道具/场景资产表、原片关键帧、逐镜分析、每段 Seedance 2.5 自包含提示词和必要的专项修复提示词。
- 摄影信息：每镜均含复刻建议设备、镜头、焦段、光圈、构图与运镜。
- 特点：正常拉片、按完整剧情动态分段、经济的代表性关键帧和脚本自动校验；提示词与深度模式使用完全相同的格式、字段完整度、去重规则和验证门槛，仅减少专业角色拆分与独立交叉复核。只在高风险或发现冲突时启动轻量 P0/P1 红队。
- 两种模式均包含：本镜可见人物表演链、动态人物首次登场、跨镜小物体/所有权转移动作链、面屏/标题/环境 VFX 分层、逐镜事实 ID 锁定时间轴，以及短促冲击事件前后约 0.20 秒加密取证。摄影方案统一追加到所属时间轴节点末尾。

### 深度分析模式

- 适合：长视频、多人物、多场景、复杂叙事/对白、连续性要求很高或包含多段复杂 VFX 的视频。
- 编排：导演、编剧、摄影、美术、提示词五个核心专业 Agent；剪辑/VFX 和声音按证据门控；最后使用一个轻量 P0/P1 红队。因此实际为 6–8 个子 Agent 分波次执行。
- 交付：仍然只交付相同两项成果，但故事板中的资产库与逐镜摄影方案更细、剧情边界由更多角色独立复核、复杂镜头关键帧更多，并包含专门的自包含提示词工程与轻量 P0/P1 审查。
- 特点：质量上限更高，专业拆分与交叉复核更多，通常需要更长处理时间。

## 询问文案

每次调用均在正常对话中发送：

> 请选择本次视频复刻模式：
>
> 1. 标准模式：标准的视频分析模式，适合大多数短视频。提供标准数量的 Agent 进行分工协助。交付两项内容：①完整故事剧本；②图文分镜故事板。故事板内整合人物、道具与场景资产表、原视频代表性关键帧、逐镜动作与摄影分析、可直接复制的 Seedance 2.5 整段提示词，以及必要的专项修复提示词。具体的 Token 消耗程度因视频长度而定。
> 2. 深度分析模式：适合复杂叙事、多人物、多场景或高连续性要求的视频。提供更多专业 Agent 进行分工和交叉复核。交付内容与标准模式相同：①完整故事剧本；②图文分镜故事板。区别在于资产、逐镜摄影、剧情边界和复杂动作的分析更细，并增加专门的提示词工程与轻量 P0/P1 审查。具体的 Token 消耗程度因视频长度而定。
>
> 请回复“标准模式”或“深度分析模式”。

询问后停止分析，等待用户回复。即使调用语句中已经写了模式偏好，也请用户用“标准模式”或“深度分析模式”确认本次选择。不要默认替用户选择，不要要求重新上传已提供的视频。

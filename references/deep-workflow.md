# 深度分析模式工作流

深度模式通常预计为标准模式的 `150%–220%`；剪辑/VFX 与声音都触发时可能达到 `180%–250%`。适合长视频、多人物、多场景、复杂对白、VFX 或高连续性项目。

## 专业分工

1. 主 Agent 建立一次紧凑证据包，并在内部 manifest 记录 Agent 门控决定。
2. 固定启动导演、编剧、摄影和美术 Agent；每个角色只读取本专业证据并输出结构化增量。
3. 按 [agent-contracts.md](agent-contracts.md) 判断是否启动剪辑/VFX 与声音 Agent；任一条件为未知时采用保守策略启动。
4. 导演只综合冲突、缺口和最终决策，不全文复述其他专业报告。
5. 提示词 Agent 只读取锁定后的结构化数据；字段缺失时返回 `NEEDS_INPUT` 并停止，数据完整后才生成 schema 4.0 自包含提示词。
6. 主 Agent 生成完整故事剧本，并从内部 `prompt-data.json` 提取原帧、渲染整合资产表、逐镜分析、每段完整提示词和专项修复提示词的图文故事板；不另行交付逐镜脚本或提示词包。
7. 确定性校验通过后，启动一个轻量红队按 [evaluation-rubric.md](evaluation-rubric.md) 只审查 P0/P1。

## 深度增量

- 摄影 Agent 逐镜提供独立 `RECREATION_SPEC`，对设备、镜头、焦段和光圈的选择给出画面依据。
- 编剧与导演分别复核每个动作关系是否明确主体、对象、空间和反馈。导演额外负责跨镜“微事件与所有权转移扫描”：用同一 `interaction_chain_id`、`interaction_kind` 和 `interaction_object_ids` 锁定对象；所有权转移必须覆盖触发/踢飞、接触/抓取、携带/返回、结果/观察者反应四类阶段，并把上一阶段 `state_out` 原样传给下一阶段 `state_in`。接触点有遮挡、快速小物体或异常轨迹时，剪辑/VFX Agent 定向复核；摄影 Agent 不替代导演判断剧情动作。
- 编剧负责人物 `performance_chain` 的情绪意图与叙事节拍；导演只验收成片可见的表情、视线、预备、执行、延续和收势。美术、摄影、物件和环境动作不得继承人物表演字段。
- 导演登记每位人物全片首次可见事件，并用至少两张本镜证据帧锁定来源空间、最先露出部位、揭示动作、第一动作和完整建立状态；动作式登场优先三帧。首次登场事实、时间轴节点和镜号必须一致且时间正向重叠。剪辑/VFX Agent 将画内面屏、后期标题、环境 VFX、UI 与转场分别归类，禁止混写。
- 美术 Agent 单独维护人物、道具、场景资产描述与跨镜状态变化，并拥有全片 `visual_master` 的最终字段所有权。它必须跨开头、中段、结尾及所有主要视觉状态识别贯穿全片的核心风格、视觉基调、色彩体系和影调结构；单段天气、地点、时间或剧情造成的变化只进入该段 `lighting_color`，不能反向改写全片母版。摄影 Agent 可提供光向、曝光和镜头质感证据，但不得另写一套竞争性的全片风格结论。
- 每个真实镜头至少一张代表帧；复杂动作和 VFX 增加状态帧。
- 对自动音频瞬态候选前后约 0.20 秒加密抽帧。导演与声音 Agent 联合验证原因→目标→反应→物理结果；无法确认时标 `UNCERTAIN`，不得擅自把摔落解释成主动动作。
- 提示词 Agent 逐段检查自包含性，并按逐镜事实 ID 编译时间轴：所有 `timeline_required=true` 的动作、表演、首次登场、分层文字/VFX 和确认冲击事件恰好进入一次；来源事实必须属于同一镜头并与节点时间正向重叠。编译后在每个时间节点末尾追加该镜摄影 `RECREATION_SPEC`；【氛围质感】不再单列摄影方案。不得改写 `timeline_fact`、自由补充或跨镜搬运。
- 剪辑/VFX 和声音 Agent 只有在证据门槛满足时读取对应素材；跳过时由主 Agent 写明依据和最低必要结论。
- 红队只读取机器校验摘要、最终 manifest、`prompt-data.json` 和必要的目标片段；不接收各专业 Agent 原始报告，不重新拉片或生成第二套分析。

## Token 纪律

共享紧凑证据包；每个角色只分析专业范围并输出 ID 对齐的结构化字段，不写视频摘要或创作感想。内部报告用资产和镜号 ID 引用已知事实，只有最终生成提示词展开自然语言。导演引用结论而不全文复述；不启动重复 Agent。红队一次初审后，没有 P0/P1 立即结束；存在 P0/P1 时只复核被修复的 ID，最多再运行一次。
